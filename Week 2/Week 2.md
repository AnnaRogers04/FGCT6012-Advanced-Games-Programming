##  Approach
I wanted to make a simple portfolio website for my games studio, Lunar Lynx Games. I planned three pages: an About page, a Projects page and a Contact page. I picked a dark look to match my logo and keep it clean. I wanted the reader to get to know me and my style.

There is also a docs page that is generated based on a code snippet ive given it this also allows the reader to see my thought process of how I create my code.

The aim of this website was to use Githuib actions and Doxyfiles to fully automate the website so any changes would automatically update on the website. This means i can sdjust and update this portfolio page whenever I need to to keep it updated with what im doing.


## Result

My website was successfully created and is live on github pages. All the pages I wanted to make I made. You can clearly see all the games on my Itch page and what they look like because of the added thumbnails. The docs page links to an old snippet of code which I really like as it was a peice of code I spent a good amount of time on and needs more exposure. Github Actions updates the pages for me everytime I push changes and it will also keep the docs updated if I change that.

The games on my Projects page come from one list in src/projects.js. My JavaScript reads that list and makes a card for each game. This means if I make a new game, I only have to add it to the list. Each card also links to my Itch page and the specific game you click.
