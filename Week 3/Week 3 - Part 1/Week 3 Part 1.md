# Week 2


##  Approach
For this task I wanted to create a horror text based narritive game. I wanted to create comething that can be visualised well.  I wanted it to be the players sole choice of what to do in order to attempt to survive, for this i decided that there was going to be no narrator. I wanted the game to speak to the player and just the player. The game has 2 good endings and 3 bad ones as seen in figure 1 and was designed to be a few minuites worth of gameplay.

For this game I used C#. The players choices are stored in string variables which are labled choice and choice2 and only allows players to select the specific numbers provided next to the choices.
